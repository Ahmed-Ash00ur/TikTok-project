# TikTok Claims Classification Project Proposal

## Overview

This proposal outlines the project to develop a predictive model to classify user-reported content on TikTok as either a "claim" or an "opinion." The high volume of user-flagged content creates a significant backlog for human moderators. This model will enable the team to efficiently prioritize reviews, improving the platform's content moderation process. The project will follow the PACE workflow, utilizing Python to perform data analysis, build a reliable machine learning model, and deliver actionable insights to key stakeholders.
